# Checklist pubblicazione firmware

- [ ] Firmware compilato senza errori
- [ ] Firmware provato sulla scheda reale
- [ ] Versione aggiornata
- [ ] Hardware compatibile verificato
- [ ] File `.bin` caricato
- [ ] Dimensione del `.bin` calcolata
- [ ] SHA-256 calcolato
- [ ] URL HTTPS verificato
- [ ] `latest.json` aggiornato
- [ ] `CHANGELOG.md` aggiornato
- [ ] Nessuna chiave, password o sorgente nel repository
- [ ] `enabled` impostato a `true` solo dopo tutti i controlli
